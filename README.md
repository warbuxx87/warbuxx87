I build the infrastructure that moves data fast and reliably between systems, and the companies around it. Over 20 years I've founded and run four companies, led engineering from first commit to production, and delivered for startups, enterprise and government, including an open data portal rolled out across 67 Ontario ministries. Techstars alum.

> **Currently:** open to remote senior engineering, engineering leadership and fractional CTO work.

### 🛠️ What I've built

| Project | What it does |
|---|---|
| 📈 **Real-time price index & market data** | Live Bitcoin/ETH VWAP index aggregated from 15+ exchanges, a trade-data API and portfolio dashboards (Node.js, Docker, AWS) |
| ⚡ **Distributed market-data platform** | Go microservices for authorization, service discovery, data relay and price indexing, plus an Angular admin console, built with my engineering team at Alkemi |
| 🏦 **Lending protocol & web app** | Solidity money-market contracts, a React/web3 app (my most-committed repo) and a Gnosis Safe integration |
| 🔁 **Event-driven automation** | NestJS liquidation service on Kubernetes with RabbitMQ, MongoDB and Flashbots, built by my team |
| 🏛️ **Government open data portal** | Delivered for the Province of Ontario across 67 ministries |
| 🤖 **Live analytics + Discord bot** | Community dashboards and bot on serverless infrastructure (public, pinned below) |

Most of this work lives in private repositories. The commit history shows on my graph, and I'm happy to walk through code on request.
